# 航班价格记录簿

> 版本：1.1.1 · 更新记录见 [CHANGELOG.md](CHANGELOG.md)

一个 Microsoft Edge（Manifest V3）扩展。浏览携程中国大陆国内单程航班列表页时，自动把该航线、日期、舱位的最低价记录在本机；打开弹窗即可查看当前价格、历史最低价、价格趋势和最近一次航班明细。本扩展为非官方工具，与携程无关联。

## 功能

- **自动记录**：打开携程单程航班列表页，列表渲染完成后自动读取航班价格；随后自动逐步滚动列表触发分批加载，必要时从顶部重新滚一轮，把全部航班都采集进来，采集完成后恢复原来的滚动位置。自动滚动期间如果你自己操作页面，采集会立即让出控制权。
- **按具体航班记录历史**：同一航班号 + 起降时间的价格变化会单独保存；价格不变时每小时最多补一个心跳点。打开完整面板可以查看单航班趋势、最低/最高价和变化。
- **日期对比**：同一条出发地/目的地、同一舱位的不同日期会分到一组，按日期对比当前最低价和历史最低价，快速找便宜日期。
- **完整面板**：弹窗中的「打开完整面板」进入独立仪表盘，包含统计概览、日期对比、航班 × 日期矩阵、单航班趋势图和最近样本表。仪表盘只读，删除/清空/导入仍在弹窗中完成。
- **弹窗查看**：
  - 航线按「出发地 → 目的地」分组，组内按日期从早到晚，组与组之间按最近一次记录时间排；
  - 当前最低价与最近记录时间；
  - 历史最低价，以及与上一次记录的价差；
  - 卡片内的迷你趋势线（最近 20 个记录）；
  - 展开后显示「航班明细」；每行显示航班号、起降时间、航司与中转情况、总用时和价格；支持按价格、用时、起飞时间排序，可切换升序/降序，最低价航班带「最低」标记；默认显示 10 条，可展开全部；
  - 存储更新导致重渲染时，保持已展开的卡片和航班排序。
- **本地管理**：删除单条航线、清空全部数据，均有二次确认。弹窗头部常驻「前往携程航班列表」入口；每张卡片标题右侧的「再查一次」会带上当前航线、日期和舱位。
- **设置与备份**：可以关闭自动采集（仍会记录你手动浏览到的航班）；支持把全部记录导出为 JSON，或导入备份（同一航线保留 `updatedAt` 较新的记录，并合并每班价格序列）。
- **按舱位区分**：不同舱位按 URL 中的 `cabin` 参数分开记录，不混在同一条趋势里。

## 安装

1. 打开 Edge 的 `edge://extensions`。
2. 打开「开发人员模式」。
3. 点击「加载已解压的扩展程序」，选择项目根目录（包含 manifest.json 的文件夹）：

4. 扩展加载后，可在工具栏的扩展列表中固定图标，方便打开弹窗。

## 使用

1. 打开携程国内单程航班列表页，例如：

   ```
   https://flights.ctrip.com/online/list/oneway-yih-cgq?depdate=2026-11-12&cabin=y_s_c_f&adult=1&child=0&infant=0
   ```

2. 等待航班列表加载完成，扩展会自动记录当前页面可见航班的最低价。
3. 点击工具栏中的扩展图标，在弹窗中查看当前价、历史最低价、迷你趋势线与最新航班明细。
4. 再次打开同一航线、同一日期的页面会累积新的价格点；同一航线、日期与舱位在 30 分钟内的多次记录会合并为一个点。

## 数据与隐私

- 数据只保存在浏览器的扩展本地存储中。
- 扩展不发送任何网络请求，不上传、不同步任何数据，所有内容都留在本机。
- 按具体航班记录的价格样本、航班号和起降时间也只在本机保存。
- 卸载扩展，或在弹窗中清空数据后，记录即被删除。

完整说明见 [隐私政策](docs/privacy-policy.html)。

## 限制

- 只支持携程中国大陆国内单程列表页；不支持往返、多程及国际/港澳台航线。
- 只记录页面能够渲染出来的航班。扩展会自动把列表滚到底部，触发携程的分批加载，正常情况下能采集到该页面的全部航班；如果携程限制了最大加载条数或滚动后仍不渲染，则以实际渲染出的航班为准，「最低价」是这些航班中的最低价。
- 自动采集最多持续约 90 秒，并可能分多轮从顶部重新滚动以触发懒加载；达到上限时会停止并保存已经采集到的部分。用户自己滚动、点击或按键会立即中断自动采集，之后手动滚出的新航班仍会继续记录。
- 单条航线最多保留 200 条航班明细；最多保存 100 条航线，超出时淘汰最久未更新的航线。
- 每班价格历史最多保留 240 个样本，全局最多 300 个航班序列，样本和序列保留 90 天；为控制存储空间，航线历史总点数也有全局上限。
- 价格是携程展示给当前账号的价格，会受登录状态、会员等级和舱位筛选影响。
- 携程页面结构改版可能导致解析失败，此时扩展不会写入数据。
- 不做后台定时查询，也不提供价格提醒或通知。

## 权限

只申请 `storage` 权限，用于在本机保存价格记录。不申请 `tabs`、`notifications`、`webRequest` 或 `host_permissions`；内容脚本只匹配 `https://flights.ctrip.com/online/list/*`。

## 开发与测试

项目使用原生 JavaScript、HTML、CSS，无框架、无构建步骤、无第三方依赖。

```bash
node tools/run-all-tests.js
```

这条命令会依次运行 Node 单元测试、五个浏览器测试（需要 Edge），并对全部脚本做语法检查。也可以用环境变量 `EDGE_PATH` 指定浏览器可执行文件路径。测试页可用 `<meta name="virtual-time-budget" content="20000">` 声明自己需要的 headless 虚拟时间。

五个浏览器测试页放在仓库根目录，脚本引用都是向下的 `src/...` 路径，因此用浏览器直接打开也能运行。想在预览面板里手动查看，可启动本地静态服务器：

```bash
node tools/serve-tests.js
```

然后打开 `http://127.0.0.1:8420/`，从列表进入任一测试页。

图标由脚本生成（纯 Node，无第三方依赖）：

```bash
node tools/make-icons.js
```

`test-fixtures.js` 由 `tools/build-fixtures.js` 从本地保存的携程页面裁剪生成；完整页面文件不提交到仓库。

商店上架所需的名称、描述、权限说明与素材见 [docs/store-listing.md](docs/store-listing.md)。

完整面板是扩展选项页，也可以在扩展详情页打开；它只读取本地数据，不新增权限。
