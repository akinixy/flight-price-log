把航班价格
记成一条线

打开携程国内航班列表，自动记录当前价、历史最低与每班价格变化。按日期对比，打开完整面板看趋势。所有数据只留在本机。

能做什么

  • 自动记录打开航班列表页后自动采集当前价格，并滚动触发分批加载。
  • 每班历史按航班号 + 起降时间记录价格变化，查看单航班趋势。
  • 日期对比同一航线不同日期的当前最低价和历史最低价放在一起比较。
  • 只存本机不发起网络请求，不上传、不同步，也没有账号和广告。

支持与反馈

遇到解析失败、价格记录异常或想提出建议，可以在 GitHub Issues 提交，并附上脱敏后的页面截图或说明。
