航班价格记录簿

隐私政策

生效日期：2026 年 11 月 2 日 · 最后更新：2026 年 11 月 2 日

「航班价格记录簿」是一款 Chrome / Edge 浏览器扩展（以下简称“本扩展”）。本扩展不是携程官方产品，与携程无关联。本政策说明本扩展处理哪些信息、如何存储，以及你可以如何控制这些信息。

1. 本扩展处理的信息

当你打开携程中国大陆国内单程航班列表页（flights.ctrip.com/online/list/*）时，本扩展会读取页面中已经展示的以下信息，用于生成价格记录：

  • 航线（出发地、目的地）、出发日期、舱位；
  • 航班价格、航班号、航空公司、起降时间、中转或经停信息；
  • 记录时间，以及同一航线、日期、舱位下的历史价格点。

本扩展还会在本地保存你的设置（是否开启自动采集），以及你主动导出或导入的 JSON 备份文件中的上述记录。

本扩展不会收集你的姓名、账号、手机号、身份证件、支付信息、精确位置、携程登录凭据或 Cookies，也不会读取当前航班列表页之外的浏览记录。

2. 信息如何存储

所有记录只保存在你当前浏览器配置文件的 chrome.storage.local 中，不会上传到任何服务器。本扩展不包含统计、广告、崩溃上报或任何第三方 SDK，也不会发起网络请求。

为了控制占用，同一航线、日期、舱位在 30 分钟内的多次记录会合并为一个价格点；单条航线最多保留 1000 个价格点和 200 条航班明细；最多保存 100 条航线，超出时淘汰最久未更新的航线。

3. 信息如何使用

  • 在扩展弹窗中展示当前价格、历史最低价、价差、趋势和最近一次航班明细；
  • 按价格、用时、起飞时间排序，帮助你比较航班；
  • 在你主动操作时导出或导入本地 JSON 备份。

我们不会将上述信息用于广告、用户画像或信用评估，也不会出售、出租或共享给任何第三方。

4. 权限说明

  • storage：在本机保存价格记录和设置。
  • flights.ctrip.com/online/list/*：读取航班列表页中已展示的价格与航班信息，用于本地记录。

本扩展不申请 tabs、notifications、webRequest 等权限，也不会在后台定时访问携程。

5. 你的控制权

  • 在弹窗设置中关闭自动采集；关闭后仍会记录你手动浏览到的航班。
  • 删除单条航线，或在弹窗中清空全部记录。
  • 卸载扩展；浏览器会删除该扩展的本地存储数据。
  • 随时导出 JSON 备份，备份文件由你自行保管。

6. 数据保留与删除

记录会一直保存在本机，直到你在弹窗中删除、清空，或卸载扩展。删除操作不可恢复；如有需要，请先导出备份。

7. 儿童

本扩展不面向儿童，也不会主动收集儿童的个人信息。

8. 政策更新

如果本扩展的数据处理方式发生变化，我们会更新本页面并修改“最后更新”日期。重大变化会在扩展更新说明中提示。

9. 联系方式

如对本政策有疑问，请通过 GitHub Issues 联系：github.com/akinixy/flight-price-log/issues。

本扩展为非官方工具，与携程旅行网无隶属、合作或授权关系。携程及相关商标归其权利人所有。

English summary

Flight Price Log is an unofficial browser extension. It reads flight prices and flight details displayed on Ctrip's domestic one-way flight list pages and stores them only in your browser's local storage. It does not collect, transmit, sell, or share personal data, and it makes no network requests. You can disable automatic collection, delete individual routes, clear all data in the popup, or uninstall the extension. Contact: GitHub Issues.
