## 简介（不超过 132 字符）

在携程国内航班列表页记录机票价格，按航班查看历史趋势与日期对比。数据仅存本机。非官方扩展，与携程无关联。

## 详细描述

打开携程中国大陆国内单程航班列表页，扩展会自动读取页面上已经加载的航班价格，并把该航线、日期、舱位的最低价记录在本机。

再次打开同一航线时，可以在弹窗里看到：

- 当前最低价与最近记录时间
- 历史最低价，以及与上次记录的价差
- 最近 20 个价格点组成的迷你趋势线
- 最近一次采集到的航班明细

弹窗中的「打开完整面板」会进入独立仪表盘：

- 统计概览：航线、城市对、追踪航班和价格样本
- 日期对比：同一条出发地/目的地、同一舱位下不同日期的当前最低价与历史最低价
- 航班 × 日期矩阵：同一航班在不同日期的当前价格
- 单航班趋势：按航班号 + 起降时间记录的价格变化、最低/最高价和最近样本表

航班明细可以按价格、用时、起飞时间排序，最低价航班带「最低」标记。航线按出发地/目的地分组，组内按日期排列；每张卡片标题右侧的「再查一次」可直达这条记录对应的携程页面。

扩展会排除红包、优惠券、立减、返现、机建/保险等金额，只把正式票价写入记录。

数据只保存在浏览器本地存储中。扩展不发起网络请求，不上传、不同步任何数据，也没有账号、广告或统计。你可以随时关闭自动采集、删除单条航线、清空全部记录，或导出/导入 JSON 备份。

限制：仅支持携程中国大陆国内单程航班列表页；只记录页面实际渲染出的航班；每班最多 240 个价格样本，全局最多 300 个航班序列，保留 90 天；价格受登录状态、会员等级和舱位筛选影响；不做后台定时查询，也不提供价格提醒。

本扩展为非官方工具，与携程旅行网无隶属、合作或授权关系。

## 权限说明

- `storage`：保存价格历史、设置和导入的备份，全部在本机。
- `https://flights.ctrip.com/online/list/*`：读取航班列表页已经展示的价格与航班信息，用于本地记录。采集期间会滚动列表以触发分批渲染；用户自己滚动、点击或按键时立即停止。扩展不修改页面内容。

## 隐私实践

- 处理的数据：网页中展示的航班价格、航班号、航司、起降时间、中转信息，以及航线、日期、舱位和每班价格样本。
- 处理方式：只写入浏览器扩展的本地存储，不上传、不共享、不出售，不用于广告或用户画像。
- 数据类别：如表单要求选择，选择「网站内容 / Website content」和「Web 历史记录 / Web history」，并注明仅本地处理。
- 远程代码：无。所有脚本都包含在扩展包内。
- 用户控制：可关闭自动采集、删除单条航线、清空全部数据、导出或导入 JSON 备份，卸载扩展即删除本地数据。

## 提交流程

### Microsoft Edge Add-ons

1. 用 Microsoft 账号登录 Partner Center，进入 Microsoft Edge 计划。
2. 新建扩展，上传 `dist/flight-price-log-1.1.1.zip`。
3. 填写名称、简介、详细描述、分类、语言、支持链接和隐私政策链接。
4. 上传 300 × 300 Logo、两张 1280 × 800 截图（弹窗、仪表盘），以及 1400 × 560 大型促销磁贴；如页面有小型促销磁贴，上传 440 × 280 版本。
5. 提交审核，通常最多 7 个工作日。

### 其他商店

本次仅提交 Microsoft Edge Add-ons；其他商店暂不提交。

## 维护

- 发布新版本前：修改 `manifest.json` 的 `version`，更新 `CHANGELOG.md`，然后运行：
  - `node tools/run-all-tests.js`
  - `node tools/build-package.js`
- 重新生成商店素材：
  - `node tools/make-store-logo.js`
  - `node tools/make-store-screenshot.js`
- 每次上架更新都必须使用更高的版本号；商店不会接受重复版本。
