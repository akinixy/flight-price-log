## 简介（不超过 132 字符）

在携程国内航班列表页记录机票价格，查看历史最低价与趋势。数据仅存本机。非官方扩展，与携程无关联。

## 详细描述

打开携程中国大陆国内单程航班列表页，扩展会自动读取页面上已经加载的航班价格，并把该航线、日期、舱位的最低价记录在本机。

再次打开同一航线时，可以在弹窗里看到：

- 当前最低价与最近记录时间
- 历史最低价，以及与上次记录的价差
- 最近 20 个价格点组成的迷你趋势线
- 最近一次采集到的航班明细

航班明细可以按价格、用时、起飞时间排序，最低价航班带「最低」标记。航线列表可以按最近更新、最低价、出发日期排序。

数据只保存在浏览器本地的 `chrome.storage.local` 中。扩展不发起网络请求，不上传、不同步任何数据，也没有账号、广告或统计。你可以随时关闭自动采集、删除单条航线、清空全部记录，或导出/导入 JSON 备份。

限制：仅支持携程中国大陆国内单程航班列表页；只记录页面实际渲染出的航班；价格受登录状态、会员等级和舱位筛选影响；不做后台定时查询，也不提供价格提醒。

本扩展为非官方工具，与携程旅行网无隶属、合作或授权关系。

## 权限说明

- `storage`：保存价格历史、设置和导入的备份，全部在本机。
- `https://flights.ctrip.com/online/list/*`：读取航班列表页已经展示的价格与航班信息，用于本地记录。采集期间会滚动列表以触发分批渲染；用户自己滚动、点击或按键时立即停止。扩展不修改页面内容。

## 隐私实践

- 处理的数据：网页中展示的航班价格、航班号、航司、起降时间、中转信息，以及航线、日期、舱位。
- 处理方式：只写入 `chrome.storage.local`，不上传、不共享、不出售，不用于广告或用户画像。
- 数据类别：如表单要求选择，选择「网站内容 / Website content」，并在说明中注明仅本地处理。
- 远程代码：无。所有脚本都包含在扩展包内。
- 用户控制：可关闭自动采集、删除单条航线、清空全部数据、导出或导入 JSON 备份，卸载扩展即删除本地数据。

## 提交流程

### Microsoft Edge Add-ons

1. 用 Microsoft 账号登录 Partner Center，进入 Microsoft Edge 计划。
2. 新建扩展，上传 `dist/flight-price-log-1.0.2.zip`。
3. 填写名称、简介、详细描述、分类、语言、支持链接和隐私政策链接。
4. 上传 300 × 300 Logo 和 1280 × 800 截图。
5. 提交审核，通常最多 7 个工作日。

### Chrome Web Store

1. 注册 Chrome Web Store 开发者账号（一次性 $5），开启两步验证。
2. 新建项目，上传同一个 zip。
3. 填写商店信息、隐私实践表单和权限用途说明。
4. 上传 128 × 128 图标和至少一张 1280 × 800 截图。
5. 提交审核，新扩展通常 2–7 天，涉及人工复核时可能更长。

## 维护

- 发布新版本前：修改 `manifest.json` 的 `version`，更新 `CHANGELOG.md`，然后运行：
  - `node tools/run-all-tests.js`
  - `node tools/build-package.js`
- 重新生成商店素材：
  - `node tools/make-store-logo.js`
  - `node tools/make-store-screenshot.js`
- 每次上架更新都必须使用更高的版本号；商店不会接受重复版本。
